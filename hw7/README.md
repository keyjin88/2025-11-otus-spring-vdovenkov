# Домашнее задание

Использовать Spring Data JPA в качестве способа доступа к данным в приложении для хранения книг в библиотеке

***Цель:***

Перевести приложение каталог книг в библиотеке на использование Spring Data JPA репозиториев в качестве технологии
доступа к данным. Задание выполняется на базе предыдущей работы. Решение должно удовлетворять нижеуказанным требованиям.

***Описание/Пошаговая инструкция выполнения домашнего задания:***

Домашнее задание выполняется переписыванием предыдущего на JPA.
Требования:

1. Подключить spring-boot-starter-data-jpa
2. Переписать все репозитории на Spring Data JPA репозитории
3. Все тесты с прошлой работы должны проходить
4. Все требования к прошлой работе, касающиеся работы со связями и транзакциями, должны быть также соблюдены (N+1, Lazy
   поля + equals/hashCode/toString и т.д.)
5. Без фанатизма :)

Код, написанный в данном ДЗ будет использоваться в дальнейших домашних заданиях всех оставшихся блоков курса
